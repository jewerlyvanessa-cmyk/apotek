# ApotikFlow — Paket & Harga

**Sistem apotik modern · multi cabang · realtime · Android · iOS · Web**  
*Juni 2026 · dokumen sales internal*

---

## Mengapa ApotikFlow?

| | |
|---|---|
| **Pelayan** input order dari HP, stok realtime | **Kasir** antrian bayar, tunai / transfer / QRIS, struk thermal |
| **Gudang** opname, batch, kadaluarsa, distribusi | **Owner** laporan penjualan & laba rugi, multi cabang |

Semua paket mendapat **fitur aplikasi yang sama**. Bedanya hanya **jumlah cabang** dan **model pembayaran**.

## Pilih Model Deployment

| | **SaaS Cloud** | **On-Prem Langganan** | **On-Prem Beli Putus** |

| Update | Termasuk | Termasuk | Patch 12 bln, lalu opsional |
| Cocok untuk | Cepat jalan, tanpa IT | Data di lokasi, budget tahunan | Investasi jangka panjang |

## Semua Paket Termasuk

- Kasir & pembayaran (tunai, transfer, QRIS)
- Order pelayan + telaah apoteker
- Katalog produk & golongan obat (merah/biru/hijau/hitam)
- Stok realtime, batch, alert kadaluarsa
- Gudang, opname, distribusi antar cabang*
- Laporan penjualan, laba rugi, top obat
- Multi peran: Owner, Manajer, Apoteker, Kasir, Pelayan, Gudang
- Mode offline + sinkronisasi otomatis
- Aplikasi Android, iOS, & browser

\*Distribusi & gudang pusat relevan untuk paket ≥2 cabang.
