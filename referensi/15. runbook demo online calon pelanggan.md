# Runbook — Demo Online untuk Calon Pelanggan

**Untuk:** tim sales / tester yang ingin menunjukkan ApotikFlow lewat internet (browser) tanpa instalasi di lokasi pelanggan.  
**Bukan:** environment produksi pelanggan bayar · **bukan** on-prem beli putus.  
**Estimasi:** 1–2 jam setup pertama · reset data 15 menit.

---

## 0. Konsep

```text
[Calon pelanggan]  browser → https://demo.app.domain.com
                              → API https://demo-api.domain.com
                              → tenant DEMO (data contoh dari seed)
```

| Pilihan | Kapan dipakai |
|---------|----------------|
| **SaaS demo** (`DEPLOYMENT_MODE=saas`) | Paling mudah — tanpa wizard lisensi, langsung login |
| VPS terpisah dari produksi | Wajib — jangan pakai server pelanggan live |
| Data dari `npm run db:seed` | Tenant `DEMO`, obat contoh, 2 cabang, multi-peran |

---

## 1. Infrastruktur minimum

Satu VPS kecil (bisa sama mesin dengan staging, **database terpisah**):

| Item | Contoh |
|------|--------|
| Subdomain app | `demo.app.apotikflow.com` |
| Subdomain API | `demo-api.apotikflow.com` |
| DB | `apotikflow_demo` (bukan DB produksi) |
| Mode | `DEPLOYMENT_MODE=saas` |
| `ENABLE_PLATFORM` | `true` (opsional, untuk tunjukkan modul Platform) |

Ikuti langkah deploy di `referensi/13. runbook saas satu vps.md`, dengan perubahan:

- Nama database & `.env` khusus demo
- Domain `demo-*` bukan `api`/`app` produksi
- **Jangan** expose Swagger (`/docs`) ke publik tanpa basic auth

## 2. Deploy API demo

```bash
# .env demo — contoh
DEPLOYMENT_MODE=saas
NODE_ENV=production
DATABASE_URL=postgresql://apotikflow:...@postgres:5432/apotikflow_demo?schema=public
PLATFORM_DATABASE_URL=postgresql://apotikflow:...@postgres:5432/apotikflow_demo?schema=public
CORS_ORIGIN=https://demo.app.apotikflow.com
JWT_SECRET=<unik-demo>
JWT_REFRESH_SECRET=<unik-demo>
```

```bash
docker compose -f docker-compose.prod.yml up -d --build
docker compose -f docker-compose.prod.yml exec api npx prisma migrate deploy
docker compose -f docker-compose.prod.yml exec api npm run db:seed
```

Seed membuat:

- Tenant **Apotik Demo Sehat** (`DEMO`)
- Cabang **Gudang Pusat** + **Cabang Utama**
- Obat contoh + stok
- Pelanggan contoh
- Akun per peran (email `@apotikflow.com` — password dari output seed / `api/prisma/seed.ts`, **kirim ke calon pelanggan lewat channel privat**, jangan di website publik)

Verifikasi:

```bash
curl -s https://demo-api.apotikflow.com/api/v1/health
```

## 3. Build Flutter web untuk demo

Gunakan flavor **staging** (URL API mengarah ke server demo Anda):

Edit `app/lib/app/config/app_config.dart` staging URL **atau** build dengan define:

```bash
cd app
flutter pub get
flutter build web --release -t lib/main_staging.dart \
  --dart-define=API_BASE_URL=https://demo-api.apotikflow.com/api/v1 \
  --dart-define=WS_BASE_URL=https://demo-api.apotikflow.com
```

> Staging build: menu **Atur alamat server** disembunyikan (`server_setup_visibility.dart`) — calon pelanggan langsung ke login.

Deploy ke nginx:

```bash
rsync -avz build/web/ vps:/var/www/apotikflow-demo-web/
```

## 4. Kartu demo untuk calon pelanggan (privat)

Siapkan PDF / slide **internal** (bukan di repo publik) berisi:

| Peran | Email (dari seed) | Alur yang ditunjukkan |
|-------|-------------------|------------------------|
| Owner | `owner@apotikflow.com` | Dashboard, stok semua cabang, laporan, admin user |
| Pelayan | `pelayan@apotikflow.com` | Buat order, cari obat/barcode |
| Apoteker | `apoteker@apotikflow.com` | Telaah resep, setujui order |
| Kasir | `kasir@apotikflow.com` | Antrian bayar, tunai/QRIS, struk |
| Gudang | `gudang@apotikflow.com` | Terima stok, mutasi |
| Manajer cabang | `manager@apotikflow.com` | Laporan cabang |

Password: dari output `npm run db:seed` di server demo (satu password dev untuk semua akun seed — **ganti setelah demo ke publik** atau reset DB mingguan).

**URL untuk dibagikan:**

```text
https://demo.app.apotikflow.com
```

## 5. Skenario demo 20 menit (script sales)

1. **Login pelayan** → buat order 2–3 item (tunjukkan stok realtime, resep jika perlu).
2. **Login apoteker** (jika ada item resep) → setujui telaah.
3. **Login kasir** → bayar tunai / campuran → unggah bukti (web).
4. **Login owner** → dashboard hari ini, laporan kasir, stok menipis.
5. (Opsional) **Super Admin** `superadmin@apotikflow.com` → Platform → tunjukkan multi-tenant (jika menjual SaaS).

Tutup dengan: *«Ini environment demo; data Anda nanti terpisah per tenant.»*

---

## 6. Keamanan demo publik

- [ ] VPS/DB **terpisah** dari produksi
- [ ] Password seed **tidak** di landing page / README publik
- [ ] Reset data berkala (mingguan):

```bash
docker compose -f docker-compose.prod.yml exec api npx prisma migrate reset --force
docker compose -f docker-compose.prod.yml exec api npm run db:seed
```

- [ ] Nonaktifkan atau basic-auth `/docs` Swagger
- [ ] `CORS_ORIGIN` hanya domain demo app
- [ ] QRIS pakai **mock/sandbox** — jangan gateway produksi
- [ ] Banner di UI: *«Lingkungan demonstrasi — data dapat direset»* (opsional, tambah di app)
- [ ] Rate limit nginx (opsional) untuk cegah abuse

---

## 7. Opsi tanpa VPS sendiri (cepat)

Untuk uji internal tim saja:

```bash
# Terminal 1 — API
cd api && npm run start:dev

# Terminal 2 — tunnel (contoh ngrok)
ngrok http 3000

# Terminal 3 — Flutter web dev
cd app && flutter run -d chrome -t lib/main_dev.dart
```

Bagikan URL ngrok **sementara** ke calon pelanggan — cocok untuk demo 1-on-1, tidak untuk marketing jangka panjang.

## 8. Perbedaan demo vs produksi vs beli putus

| | Demo online | SaaS produksi | Beli putus |
|--|-------------|---------------|------------|
| Server | VPS demo Anda | VPS produksi | Server pelanggan |
| Data | Seed DEMO, reset | Tenant pelanggan sungguhan | Data pelanggan |
| Lisensi | Tidak perlu | Langganan SaaS | Kode perpetual |
| App entry | `main_staging.dart` | `main_production.dart` | APK + atur server |
| Password di docs | Tidak (privat) | Tidak | Tidak |

---

## 9. Troubleshooting

| Masalah | Solusi |
|---------|--------|
| Login gagal | Cek seed sudah jalan, tenant DEMO aktif |
| Stok kosong | Jalankan ulang seed |
| CORS | `CORS_ORIGIN` = URL demo app persis |
| Calon pelanggan ubah data kacau | Reset DB + seed |
| Ingin tenant terpisah per prospect | Platform → buat tenant baru (SaaS demo) |
