# PRD — Aplikasi Apotik Multi-Tenant

## Nama Produk
ApotikFlow

---

# 1. Ringkasan Produk

Aplikasi apotik berbasis multi-tenant yang memungkinkan banyak pemilik apotik menggunakan satu platform dengan data yang terisolasi.

Setiap apotik dapat memiliki:
- Banyak cabang
- Banyak pegawai
- Banyak kasir
- Banyak pelayan
- Gudang dan stok masing-masing

Keunggulan utama sistem:
- Pelayan apotik dapat menerima pesanan langsung dari HP Android/iPhone
- Pelayan dapat melihat stok realtime saat input pesanan
- Pesanan langsung masuk ke antrian kasir
- Kasir tinggal membuka daftar order siap bayar
- Kasir dapat menggunakan HP, tablet, laptop, atau desktop
- Realtime sinkronisasi stok antar cabang
- Mendukung mode semi-offline

Teknologi:
- Frontend: Flutter
- Backend: Node.js
- Database: PostgreSQL
- Realtime: Socket.IO / WebSocket
- Cache: Redis
- Deployment: Docker + Kubernetes

# 2. Tujuan Produk

## Tujuan Utama
Membuat sistem apotik modern yang:
- Cepat

- Waktu input pesanan < 1 menit

- Downtime < 0.1%

- 1 kasir dapat melayani > 100 transaksi/hari
