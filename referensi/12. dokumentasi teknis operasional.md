## 1. WebSocket realtime

| Item | Detail |
|------|--------|
| Gateway | `api/src/websocket/events.gateway.ts` |
| Auth | JWT di `handshake.auth.token` atau header `Authorization` |
| Room | `tenant:{tenantId}`, `branch:{branchId}` |

### Event yang dipancarkan

| Event | Payload utama |
|-------|----------------|
| `order.created` | `order_id`, `order_number` |
| `order.updated` | `order_id`, `status` |
| `payment.completed` | `payment_id`, `order_id`, `amount` |
| `stock.low` | `medicine_id`, `available_quantity` |
| `batch.expired` | `medicine_name`, `days_left` |
| `subscription.warning` | `tenant_name`, `days_left` |

### Multi-instance (Redis)

Set `REDIS_URL` di `api/.env` → Socket.IO memakai `@socket.io/redis-adapter` otomatis. Tanpa Redis, mode single-process tetap jalan.

**Flutter:** `app/lib/core/websocket/socket_service.dart` — connect setelah login.

## 2. Offline sync (Flutter)

| Item | Path |
|------|------|
| Queue | `app/lib/core/offline/pending_actions_storage.dart` |
| Processor | `app/lib/core/offline/sync_manager.dart` |
| UI antrian | `/pending-actions` |

### Tipe aksi yang di-queue

- `CREATE_ORDER` → `POST /orders`
- `PAY_ORDER` → `POST /payments` (termasuk `splits[]`)
- `ADJUST_STOCK`, `STOCK_MUTATION`, `CASH_ENTRY`

Sinkron otomatis saat jaringan kembali (login + `processQueue`). Konflik HTTP 400 pada pembayaran yang sudah lunas dianggap sukses.

## 5. Monitoring & health

| Endpoint | Fungsi |
|----------|--------|
| `GET /api/v1/health` | Readiness — cek DB tenant + platform + Redis; **503** jika DB down |
| `GET /api/v1/health/live` | Liveness — proses API hidup |

Response `health` mencakup `checks.database`, `checks.platform_database`, `checks.redis`, flag `sentry_configured`.

**Sentry (opsional):** set `SENTRY_DSN` di `api/.env`, pasang `@sentry/node` di `main.ts` saat go-live production.

**Uptime:** pantau `/health` tiap 1–5 menit (Uptime Kuma, Pingdom, atau cron `curl`).

## 8. SSL pinning (opsional — mobile/desktop)

| Item | Detail |
|------|--------|
| Kode | `app/lib/core/network/ssl_pinning_*.dart` |
| Platform | Android / iOS / desktop (`dart:io`). **Web tidak didukung.** |
| Aktifkan | Build dengan `--dart-define` |

```bash
# Fingerprint sertifikat API (HTTPS)
openssl s_client -connect api.apotek.lan:443 </dev/null 2>/dev/null \
  | openssl x509 -outform DER | openssl dgst -sha256 -hex

flutter build apk --release -t lib/main_production.dart \
  --dart-define=ENABLE_SSL_PINNING=true \
  --dart-define=SSL_PIN_SHA256=<hex tanpa spasi, bisa beberapa dipisah koma>
```

**Catatan:** pinning ini memvalidasi sertifikat saat sistem tidak mempercayai CA (mis. self-signed on-prem). Untuk API HTTP di LAN, fitur ini tidak diperlukan.
