# Paket & Fitur Aplikasi ApotikFlow

**Produk:** ApotikFlow — sistem apotik multi-tenant (Flutter + NestJS + PostgreSQL)  
**Sumber kebenaran paket:** `api/src/modules/license/license-plans.ts`  
**Terakhir diperbarui:** Juni 2026

---

## 1. Ringkasan

ApotikFlow dijual dalam dua **model deployment**:

| Model | `DEPLOYMENT_MODE` | Cara bayar | Siapa yang kelola server |
|-------|-------------------|------------|---------------------------|
| **SaaS (cloud)** | `saas` | Berlangganan per tenant | Vendor / tim internal |
| **On-premise** | `on_prem` | Beli putus **atau** berlangganan tahunan | Pelanggan (server di lokasi mereka) |

**Prinsip paket:** Semua paket resmi memakai **fitur aplikasi yang sama**. Perbedaan paket hanya pada:

- **Jumlah maksimum cabang** (`max_branches`)
- **Masa berlaku** (selamanya vs perpanjangan tahunan)
- **Model penagihan** (SaaS vs lisensi on-prem)

Pembatasan cabang ditegakkan di API (`LicenseService.assertBranchLimit`). Saat ini **tidak ada** pembatasan fitur per `plan id` di kode (mis. Starter tidak memblokir laporan laba rugi).

## 2. Katalog Paket Aplikasi

### 2.1 SaaS — Berlangganan Cloud

Untuk tenant yang di-host di server vendor. Paket disimpan di kolom `tenants.subscription_plan`.

| ID paket | Nama tampilan | Maks. cabang | Masa berlaku | Keterangan |
|----------|---------------|--------------|--------------|------------|
| `starter` | Starter | 1 | 365 hari | Apotik tunggal |
| `professional` | Profesional | 3 | 365 hari | Multi cabang kecil |
| `enterprise` | Enterprise | 10 | 365 hari | Jaringan cabang menengah |
| `custom` | Kustom | Sesuai kontrak | Sesuai kontrak | Diatur manual Super Admin |

**Perpanjangan:** modul billing SaaS (`SubscriptionBillingService`) — intent perpanjangan + webhook. UI perpanjangan tersedia di form tenant Platform (`SaasRenewalSection`).

**Catatan operasional:** seed development memakai `subscription_plan: trial` — ini **bukan** paket katalog resmi, hanya label internal demo.

---

### 2.2 On-Premise — Beli Putus (Perpetual)

Server di lokasi pelanggan. Lisensi **tidak kedaluwarsa** setelah aktivasi.

| ID paket | Nama tampilan | Maks. cabang | Masa berlaku |
|----------|---------------|--------------|--------------|
| `single` | Single | 1 | Selamanya |
| `standard` | Standard | 3 | Selamanya |
| `enterprise` | Enterprise | 10 | Selamanya |
| `custom` | Kustom | Sesuai kontrak | Selamanya |

**Aktivasi:** kode lisensi via `/license/activate` atau wizard on-prem (`/platform/wizard`).  
**Generate kode:** Platform → Lisensi, atau CLI `npm run license:generate`.

---

### 2.3 On-Premise — Berlangganan Tahunan

Server tetap di lokasi pelanggan, tetapi lisensi **wajib diperpanjang** (default 365 hari per siklus).

| ID paket | Nama tampilan | Maks. cabang | Masa berlaku |
|----------|---------------|--------------|--------------|
| `starter` | Starter | 1 | 365 hari |
| `professional` | Profesional | 3 | 365 hari |
| `enterprise` | Enterprise | 10 | 365 hari |
| `custom` | Kustom | Sesuai kontrak | Sesuai kontrak |

ID paket sama dengan SaaS, tetapi `license_type` = `subscription` (bukan `perpetual`).

---

### 2.4 Paket Kustom

Paket `custom` dipakai ketika:

- Jumlah cabang di luar katalog (mis. 15 cabang)
- Masa berlaku negosiasi (mis. 2 tahun)
- Kontrak enterprise khusus

Diatur manual saat generate lisensi atau edit tenant oleh Super Admin (`max_branches`, `extend_days`).

## 3. Matriks Perbandingan Paket

| Aspek | Starter / Single | Profesional / Standard | Enterprise | Kustom |
|-------|------------------|------------------------|------------|--------|
| Maks. cabang | 1 | 3 | 10 | Bebas |

| Multi cabang & distribusi | ❌* | ✅ | ✅ | ✅ |
| Gudang pusat tenant | ❌* | ✅ | ✅ | ✅ |

## 4. Fitur Aplikasi (Semua Paket)

Daftar berikut mencerminkan modul yang **sudah ada** di aplikasi per Juni 2026. Akses aktual juga dibatasi **peran pengguna** (lihat §5).

### 4.1 Platform & Keamanan

| Fitur | Keterangan |
|-------|------------|
| Login multi-peran | Owner, Manajer, Apoteker, Kasir, Pelayan, Gudang |
| JWT + refresh token | Sesi aman, ganti password wajib |
| Login biometrik | Android / iOS (sidik jari / Face ID) |
| Multi-tenant | Data terisolasi per apotik |
| RBAC | Route & menu sesuai peran aktif |
| Audit log | Jejak perubahan penting (API) |
| Mode offline | Antrian aksi saat putus jaringan, sinkronisasi otomatis |
| Notifikasi | Pusat notifikasi in-app |
| Pencarian global | Cari obat / order dari menu utama |
| Scan barcode | Input cepat via kamera |

### 4.2 Penjualan & Kasir

| Fitur | Keterangan |
|-------|------------|
| Buat order (pelayan) | Input obat, cek stok realtime, reservasi stok |
| Telaah apoteker | Review order sebelum ke kasir (alur farmasi) |
| Antrian kasir | Order menunggu pembayaran |
| Pembayaran | Tunai, transfer, QRIS, split payment |
| Kas cabang | Uang masuk/keluar manual, saldo harian |
| Cetak struk thermal | WiFi / Bluetooth (mobile & desktop; web terbatas) |
| Laporan kasir | Per cabang, per periode |

### 4.3 Katalog & Produk

| Fitur | Keterangan |
|-------|------------|
| Katalog produk | CRUD obat/non-obat (Owner / Manajer / Gudang) |
| Kategori, satuan, tipe produk | Master data tenant |
| Golongan obat | Merah, biru, hijau, hitam (`drug_classification`) |
| Barcode & gambar produk | Upload foto katalog |
| Harga beli / jual / margin | Per produk |
| Batch & kadaluarsa | Pelacakan batch stok |
| Alert kadaluarsa | Daftar batch mendekati / sudah expired |

### 4.4 Inventori & Gudang

| Fitur | Keterangan |
|-------|------------|
| Stok realtime | `available_quantity` per cabang |
| Stok tenant / cabang | Tampilan agregat & per lokasi |
| Gudang cabang & etalase | Lokasi `back` / `front` |
| Isi etalase | Mutasi internal gudang → etalase |
| Terima stok | Penerimaan barang ke cabang |
| Stok opname | Penghitungan fisik |
| Transfer stok | Antar lokasi / cabang |
| Mutasi stok | Riwayat pergerakan |
| Stok gudang pusat | Agregat gudang pusat tenant |
| Mode stok cabang | Konfigurasi per cabang (Owner / Manajer) |

### 4.5 Pengadaan & Distribusi *(bermakna jika ≥2 cabang)*

| Fitur | Keterangan |
|-------|------------|
| Pengadaan (PO) | Pembelian ke supplier, level tenant |
| Distribusi ke cabang | Kirim stok pusat → cabang |
| Terima distribusi | Konfirmasi penerimaan di cabang |

### 4.6 Pelanggan & Laporan

| Fitur | Keterangan |
|-------|------------|
| Data pelanggan | CRUD pelanggan tenant |
| Laporan Owner / Manajer pusat | Ringkasan, penjualan, laba rugi, top obat, kadaluarsa |
| Laporan cabang | Manajer cabang |
| Laporan pelayan / apoteker | Order per periode |
| Ekspor & cetak laporan | PDF / printer (platform-dependent) |

### 4.7 Administrasi Tenant

| Fitur | Keterangan |
|-------|------------|
| Kelola cabang | Tambah / edit cabang (terbatas `max_branches`) |
| Kelola user | Undang pegawai, assign peran & cabang |
| Backup lokal | Export data tenant (Owner / Manajer) |
| Status lisensi | Owner melihat masa berlaku & paket |
| Pengaturan printer | Kasir / Manajer / Owner |

### 4.8 Modul Platform *(Super Admin)*

Hanya pada instalasi dengan `ENABLE_PLATFORM=true` (default SaaS).

| Fitur | Keterangan |
|-------|------------|
| Daftar tenant | CRUD tenant SaaS |
| Kelola cabang tenant | Dari konsol platform |
| Generate & aktivasi lisensi | On-prem perpetual / subscription |
| Perpanjang langganan SaaS | Per tenant |
| Backup platform | Administrasi sistem |
| Wizard on-prem | Server → DB → lisensi → tenant |

## 5. Fitur per Paket (Ringkas)

Karena tidak ada feature flag per tier, gunakan tabel ini untuk komunikasi ke pelanggan:

### 5.1 Fitur yang **sama** di semua paket resmi

Semua modul di §4.1–4.3, §4.6 (laporan), §4.7, dan §4.8 (jika deployment SaaS) — **termasuk** kasir, QRIS, offline, golongan obat, backup lokal, dll.

### 5.2 Fitur yang **bergantung jumlah cabang** (bukan tier nama paket)

| Fitur | Starter / Single (1 cabang) | Profesional+ / Standard+ (≥2 cabang) |
|-------|----------------------------|--------------------------------------|
| Transfer antar cabang | Tidak dipakai | ✅ |
| Distribusi pusat → cabang | Tidak dipakai | ✅ |
| Pengadaan pusat multi-cabang | Terbatas 1 lokasi | ✅ |
| Laporan agregat multi-cabang | Setara 1 cabang | ✅ |
| Monitoring stok lintas cabang | Tidak relevan | ✅ |

### 5.3 Perbedaan **model deployment** (bukan nama paket)

| Fitur / aspek | SaaS (`saas`) | On-prem (`on_prem`) |
|---------------|---------------|---------------------|
| Hosting | Vendor | Pelanggan |
| Wizard setup server & DB | Opsional (demo) | ✅ Wajib pertama kali |
| Aktivasi kode lisensi | Tidak (langganan tenant) | ✅ |
| Perpanjangan via billing webhook | ✅ | Via kode lisensi baru |
| Modul Platform Super Admin | ✅ (default) | ❌ (`ENABLE_PLATFORM=false`) |
| Cetak thermal Bluetooth | Mobile | Mobile |
| Cetak thermal di browser | Terbatas | Terbatas |

## 6. Akses Fitur per Peran (RBAC)

Paket menentukan **berapa cabang**; peran menentukan **menu apa** yang tampil. Ringkasan:

| Peran | Menu utama |
|-------|------------|
| **Owner** | Semua modul tenant: cabang, user, pelanggan, laporan, kas, stok, pengadaan, distribusi, katalog, telaah, backup, lisensi |
| **Manajer pusat** | Sama Owner kecuali status lisensi & telaah apoteker |
| **Manajer cabang** | Cabang sendiri: stok, gudang, etalase, distribusi, laporan cabang, kas |
| **Apoteker** | Telaah order, stok, katalog (baca), alert kadaluarsa, laporan order |
| **Pelayan (Staff)** | Buat order, cek stok, laporan order |
| **Kasir** | Kasir, pembayaran, kas cabang, laporan kasir, printer |
| **Gudang** | Stok, terima barang, opname, transfer, gudang pusat, distribusi, katalog (baca) |
| **Super Admin** | Hanya modul `/platform` |

Sumber: `app/lib/core/auth/route_access.dart`, `home_quick_menu.dart`.

## 7. Rekomendasi Penawaran ke Pelanggan

### Apotik tunggal
→ **Starter** (SaaS) atau **Single** (on-prem beli putus)

### 2–3 cabang
→ **Profesional** / **Standard**

### 4–10 cabang
→ **Enterprise**

### >10 cabang atau SLA khusus
→ **Kustom** + kontrak terpisah
