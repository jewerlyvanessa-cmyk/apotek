# Runbook — Full Online (SaaS) di Satu VPS

**Untuk:** menjalankan ApotikFlow sebagai layanan berlangganan (multi-tenant) di satu server cloud.  
**Estimasi waktu:** 2–4 jam (termasuk DNS + SSL).  
**Relasi:** `referensi/12. dokumentasi teknis operasional.md`, `docker-compose.prod.yml`

---

## 0. Ringkasan arsitektur

```text
Internet
   │
   ▼
[VPS]  nginx :443
         ├── app.domain.com     → Flutter web (build/)
         └── api.domain.com     → NestJS :3000 (/api/v1, /socket.io)
              ├── PostgreSQL :5432 (localhost only)
              └── Redis :6379 (opsional tapi disarankan)
```

| Komponen | Spesifikasi minimum |
|----------|---------------------|
| VPS | 2 vCPU, 4 GB RAM, 40 GB SSD (Ubuntu 22.04 LTS) |
| Domain | 2 subdomain: `app.*` dan `api.*` (atau satu domain + path) |
| Mode API | `DEPLOYMENT_MODE=saas` |

## 1. Persiapan VPS

```bash
# Login ke VPS
ssh root@your-vps-ip

apt update && apt upgrade -y
apt install -y git nginx certbot python3-certbot-nginx ufw

# Firewall
ufw allow OpenSSH
ufw allow 'Nginx Full'
ufw enable
```

Pasang Docker (disarankan):

```bash
curl -fsSL https://get.docker.com | sh
apt install -y docker-compose-plugin
```

## 2. Deploy dari repo (vendor)

Di mesin build **atau** langsung di VPS (clone private repo):

```bash
git clone <repo-apotikflow> /opt/apotikflow-src
cd /opt/apotikflow-src
```

### 2.1 Konfigurasi environment

```bash
cp api/.env.example api/.env
nano api/.env
```

Isi minimal production SaaS:

```env
DEPLOYMENT_MODE=saas
NODE_ENV=production

JWT_SECRET=<openssl rand -hex 32>
JWT_REFRESH_SECRET=<openssl rand -hex 32>

# Akan di-override oleh docker-compose untuk host postgres — tetap isi untuk manual run
DATABASE_URL=postgresql://apotikflow:STRONG_DB_PASS@postgres:5432/apotikflow?schema=public
PLATFORM_DATABASE_URL=postgresql://apotikflow:STRONG_DB_PASS@postgres:5432/apotikflow?schema=public

PORT=3000
API_PREFIX=api/v1
CORS_ORIGIN=https://app.domain-anda.com

REDIS_URL=redis://redis:6379
REDIS_PREFIX=apotikflow

ENABLE_PLATFORM=true

# QRIS production (ganti mock)
QRIS_PROVIDER=xendit
QRIS_XENDIT_SECRET_KEY=xnd_...
QRIS_WEBHOOK_SECRET=<openssl rand -hex 24>
QRIS_CALLBACK_URL=https://api.domain-anda.com/api/v1/payments/qris/webhook

# Opsional
# SENTRY_DSN=...
# BILLING_WEBHOOK_SECRET=...
```

Buat file env root untuk Docker:

```bash
cat > .env <<'EOF'
POSTGRES_USER=apotikflow
POSTGRES_PASSWORD=GANTI_PASSWORD_DB_KUAT
POSTGRES_DB=apotikflow
API_PORT=3000
EOF
```

### 2.2 Jalankan stack

```bash
docker compose -f docker-compose.prod.yml up -d --build
docker compose -f docker-compose.prod.yml exec api npx prisma migrate deploy
```

**Seed hanya untuk bootstrap awal** (buat Super Admin platform):

```bash
docker compose -f docker-compose.prod.yml exec api npm run db:seed
# Catat email dari output seed — ganti password segera setelah login
```

Terapkan permission DB tenant (setelah migrasi):

```bash
docker compose -f docker-compose.prod.yml exec postgres psql -U apotikflow -d apotikflow -f - < api/prisma/sql/tenant-db-permissions.sql
# Atau jalankan npm run db:tenant-permissions dari host jika script tersedia
```

Verifikasi:

```bash
curl -s http://127.0.0.1:3000/api/v1/health | jq .
# success: true, checks.database: ok
```

## 3. Build & deploy Flutter web

Di mesin yang punya Flutter SDK:

```bash
cd app
flutter pub get
flutter build web --release -t lib/main_production.dart \
  --dart-define=API_BASE_URL=https://api.domain-anda.com/api/v1 \
  --dart-define=WS_BASE_URL=https://api.domain-anda.com
```

> Jika tidak pakai `--dart-define`, app memakai URL bawaan `api.apotikflow.com` di `app_config.dart`. Untuk domain sendiri, **wajib** override saat build **atau** arahkan DNS ke domain tersebut.

Salin ke VPS:

```bash
rsync -avz build/web/ root@your-vps:/var/www/apotikflow-web/
```

## 4. nginx + SSL

### API (`api.domain-anda.com`)

```nginx
upstream apotikflow_api {
    server 127.0.0.1:3000;
}

server {
    listen 80;
    server_name api.domain-anda.com;
    location / {
        proxy_pass http://apotikflow_api;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    location /socket.io/ {
        proxy_pass http://apotikflow_api;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 86400s;
    }
}
```

### App web (`app.domain-anda.com`)

```nginx
server {
    listen 80;
    server_name app.domain-anda.com;
    root /var/www/apotikflow-web;
    index index.html;
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

Aktifkan + SSL:

```bash
sudo ln -s /etc/nginx/sites-available/apotikflow-api /etc/nginx/sites-enabled/
sudo ln -s /etc/nginx/sites-available/apotikflow-app /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

sudo certbot --nginx -d api.domain-anda.com -d app.domain-anda.com
```

## 5. Go-live operasional

| # | Tugas | Siapa |
|---|-------|-------|
| 1 | Login Super Admin → ganti password | Vendor |
| 2 | Platform → buat tenant pertama (apotek pelanggan) | Vendor |
| 3 | Set `subscription_plan` / perpanjang langganan | Vendor |
| 4 | Owner tenant login → buat cabang & user | Pelanggan / vendor bimbing |
| 5 | Master obat, stok, uji order → kasir → bayar | Pelanggan |
| 6 | Backup PostgreSQL harian | Vendor (cron) |
| 7 | Pantau `/api/v1/health` tiap 5 menit | Vendor |

Backup contoh:

```bash
docker compose -f docker-compose.prod.yml exec postgres \
  pg_dump -U apotikflow apotikflow | gzip > /backup/apotikflow-$(date +%F).sql.gz
```

## 6. Checklist sebelum buka ke publik

- [ ] `JWT_SECRET`, `JWT_REFRESH_SECRET` unik (bukan default `.env.example`)
- [ ] `DEPLOYMENT_MODE=saas`
- [ ] PostgreSQL tidak expose port 5432 ke internet (`ufw` + bind localhost)
- [ ] HTTPS aktif di app dan API
- [ ] `CORS_ORIGIN` hanya domain app (bukan `*` di production publik)
- [ ] QRIS provider nyata + webhook secret di-set
- [ ] Akun seed tidak dipakai operasional (password diganti)
- [ ] Upload folder `api/uploads` / volume `api_data` ikut dibackup
- [ ] Health check terpasang (Uptime Kuma / cron `curl`)

## 7. Troubleshooting cepat

| Gejala | Periksa |
|--------|---------|
| 502 Bad Gateway | `docker compose ps`, log API: `docker compose logs api -f` |
| CORS error di browser | `CORS_ORIGIN` di `.env` harus match `https://app.domain-anda.com` |
| WebSocket putus | nginx `location /socket.io/` + `Upgrade` header |
| Login 401 semua user | DB down / migrasi belum jalan — cek `/health` |
| Tenant tidak bisa dibuat | `PLATFORM_DATABASE_URL` + permission `apotikflow_platform` |
